# Shop Assistant starter contract

This is a local teaching project, not a real commerce system. Read `README.md`
and `stages/README.md` before changing a stage. Keep the stage-0 learning path
small and runnable; stage reference implementations belong in separate,
versioned refs, not in the default checkout. Use Python 3.12+ standard library
for the baseline. Run `scripts/test` after changing business functions, fixtures,
or the workbench; run `scripts/verify-stage 0` for the initial checkpoint.

All customers, orders, receipts and policies are fictional. Identity is an
explicit **simulated local state**, not authentication. Refunds only write the
local teaching ledger; never contact payment systems. The preset demo is fixed
logic, not a model or an agent. Do not invent live integration evidence from
fixtures, commit credentials, or print local `.env` values. Future Claude
Code/Agent SDK/MCP exercises must pin versions and report their own live checks.

Prefer a learner prediction, observable practice and evidence inspection over
long theory or memorized feature names. Every unfinished stage stays NOT_READY
until its own implementation and checks exist.
