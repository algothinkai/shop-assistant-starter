# Claude Code entry point

This repository is a fictional coffee-equipment support teaching project.
Start with `README.md`, `stages/README.md`, and the current checkpoint only.
Before editing, ask the learner to choose a method and predict observable
evidence. Help within that checkpoint's modification scope, explain trade-offs,
and point to `scripts/test` or `scripts/verify-stage N` for inspection. Do not
complete future stages, reveal their reference solutions, or claim that Codex
or preset fixtures verify Claude Code behavior. Never read or print `.env`.

Stage 1 will add scoped rules and skills experiments in a separate version.
This baseline has no Claude Code hooks, MCP configuration, or live model call.
